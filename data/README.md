The experiments use the **Central Bank Speeches** dataset available through Kaggle:
https://www.kaggle.com/datasets/magnushansson/central-bank-speeches
The dataset provides a collection of central bank speeches. The version originally used for this study contained 16,554 unique speeches covering the period from 1997 to 2022.
A sample of the available speeches was selected for the present study. Based on speeches from this sample, a curated domain-specific question-answer benchmark was constructed.

## Question-Answer Benchmark
The experimental benchmark consists of:
- 150 curated questions
-  Corresponding reference answers
-  Questions derived from different central bank speeches in the selected sample
The 150 question-answer pairs were used to evaluate the RAG system across the experimental configurations.
The current version of the Kaggle dataset may contain speeches beyond the period covered by the dataset version used in the study. Therefore, the dataset version and speech sample used for reproduction should correspond to the data configuration described in the thesis.
